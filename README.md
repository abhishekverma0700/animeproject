# Abhishek — Editorial Portfolio

A high-performance dark editorial portfolio built with Next.js 14 App Router, TypeScript, and Tailwind CSS. Features smooth inertial scrolling (Lenis), scrubbed ScrollTrigger timelines (GSAP), interactive 3D WebGL scenes (Three.js / React Three Fiber / Drei), and fluid UI interactions (Framer Motion).

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Anton (Google Font)
- **3D & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations & Scroll**: GSAP, ScrollTrigger, Lenis Smooth Scroll, Framer Motion

## Getting Started

```bash
# Install dependencies
npm i

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm run start
```
